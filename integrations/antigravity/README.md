# Antigravity integration

The `antigravity` provider dispatches to `agy`. Skills use the standard `.agents/skills` discovery tree, lifecycle MCP configuration uses Antigravity's `mcp_config.json`, and lifecycle events use its native hook configuration.

Constellation consumes stream-JSON, saves the native conversation ID, and resumes with `--conversation` on trusted full-auto runtime hosts. Because no stable non-interactive vendor uninstall contract is assumed, OpenCROW purges only receipt-owned `agy` install paths inside the target home and reports anything else as unresolved.
