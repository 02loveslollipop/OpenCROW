# Native proxy quick reference

The full web toolbox provides `opencrow-web-proxy-mcp`, the same `web_proxy_*` tools through `opencrow-web-mcp`, and `opencrow-web-proxy`. Skills-only installations do not include the service. Probe these commands before use. The runtime is Python 3.12+, h11 0.16.0 and cryptography 50.0.2; `toolbox_verify` reports readiness without starting listeners.

Start `web_proxy_start` with an existing workspace and exact authorized `targets`: each has `host`, `port`, optional `path_prefix` and explicit `allow_private` for local/private addresses. The proxy binds loopback with route authentication; its control socket and raw history are private. Observation and opaque HTTPS are defaults. Model/provider APIs are excluded. Never put a tool's HTTP proxy environment on a model/provider process.

Run tools with `opencrow-web-proxy env SESSION_ID -- COMMAND` to supply private route authentication without printing it. Set `proxy_session_id` on worker start to retain correlation and a public history reference across turns. OpenCode uses a native tool environment; CLI workers support Bash command shells and the explicit launcher for other tools. Browsers need an explicit authenticated proxy object in their launch script. Direct sockets and applications ignoring proxies are not captured.

Inspect `web_proxy_history`, `web_proxy_request_get` and `web_proxy_response_get`. Set `web_proxy_intercept_set` to pause, edit by request ID, then forward/drop once. Pause defaults to a 15-second deadline and dropping on expiry; choose forward-on-expiry explicitly. Edits accept URL, method, header map, removed headers and body_base64. Host/framing headers are computed; replace a compressed body only after removing Content-Encoding. Edited requests are limited to 1 MiB. Responses stream unchanged.

Replay is explicit and asynchronous; poll its new request ID. POST and other methods with possible side effects require `confirm_side_effects: true`; truncated uploads and opaque tunnels cannot be replayed. Replay bypasses interception rules. Use `web_proxy_compare`, or export bounded sanitized HAR/JSONL through `web_proxy_export`.

For `tls_intercept: true`, trust the returned public CA only in the test client. The command launcher supplies process-local trust alongside system roots; no global roots are installed and upstream TLS verification stays enabled. Stop destroys the CA/private keys; restart creates a new CA, so refresh client trust. Inspected traffic supports HTTP/1.1; HTTP/2 is declined and WebSocket upgrades return 426. Opaque CONNECT passes encrypted HTTP/2/WebSockets without inspection. SSE/chunked/binary responses stream with bounded capture and a finite request lifetime.

Summaries omit bodies, redact query values and credential headers, and suppress unknown header values. Paths and approved public headers remain visible. Raw reads require both session creation with `allow_raw_access: true` and an explicit `raw: true` read, bounded to 16 KiB. Do not enable raw access for ordinary metadata. Raw history/keys stay outside project artifacts; exports contain sanitized metadata only.

Stop the owned session with `web_proxy_stop`. History remains readable after stop; explicit `web_proxy_delete` removes a terminal request or a stopped session. Crashes interrupt pending requests without resending them. Restart with only the saved session_id to retain scope. Default capture is 64 KiB/body; retention is 500 requests, 32 MiB terminal history and 24 hours, with bounded active records. No proxy is started or trusted by installation.
