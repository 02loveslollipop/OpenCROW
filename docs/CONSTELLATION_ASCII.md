# Constellation ASCII Header

This is the text-based Constellation header source for the README. It follows the same general terminal-banner direction as `opencrow-autosetup` and `opencrow-exploit`: an OpenCROW crow icon plus a monospace wordmark.

The reusable multi-size wordmark set lives in [constellation_ascii_text.md](./constellation_ascii_text.md). The current README header uses the `xsmall` variant from that file.

             @@@@@@

Follow-up options:

- tighten the crow icon if you want it closer to the final OpenCROW identity
- switch the README banner between the `xsmall`, `small`, `medium`, or `large` wordmark variants
- add alternate compact variants if this banner needs to be reused in terminals or docs outside the README
