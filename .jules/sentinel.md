## 2024-07-22 - Prevent Timing Attacks in Token Validation\n**Vulnerability:** Simple `in` string check was used to validate system tokens in `constellation/storage.py`, making it vulnerable to timing attacks where an attacker could theoretically guess valid tokens character by character.\n**Learning:** System tokens require constant-time comparison methods, just like any other security secret or authentication token.\n**Prevention:** Always use constant-time comparison methods (like `secrets.compare_digest`) for any secret, password, or token verification across the application.
